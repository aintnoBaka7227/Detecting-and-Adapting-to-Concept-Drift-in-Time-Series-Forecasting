# Aditya's Contributions

| PR | Branch | Description | Stage |
| --- | --- | --- | --- |
| #15 | `feature/S2-XGBoost` (merged into `main`) | Built `XGBoostForecaster` (`src/drift_lab/forecasting/xgboost_forecaster.py`) on the frozen `Forecaster` contract. It uses lag features (a contiguous range up to 48 half-hours, plus 2-day, 3-day and weekly lags) and calendar features (hour, minute, day of week, month). `fit` uses the training window only. `predict` forecasts one row at a time, recursively, and takes observed lags where they exist, so the model can be fitted once and rolled through the test stream without leakage. Early stopping uses a chronological validation slice taken from the end of the training window. Added tests in `tests/test_xgboost_forecaster.py` and generated the baseline forecast CSVs. | Forecasting |
| #22 | `docs/s2-research-gradient-boosting` (merged into `main`) | Added the research notebook `notebooks/research/gradient_boosting.ipynb`. It explains what XGBoost is, its architecture and how it works, and how it connects to the four adaptation arms. It references two research papers, and it walks through the lag and calendar features with worked examples. Also documented `fit`, `predict()` and `observe()` in the forecaster. | Forecasting |
| #28 | `feature/s3-evaluation-metrics` (merged into `main`) | Built the detection-evaluation layer in `src/drift_lab/evaluation/evaluation.py`, with tests in `tests/test_evaluation.py`. Added `match_unmatch`, which debounces detections and matches them one-to-one to documented AEMO events, Tier 1 before Tier 2, and reports unmatched detections as "Unmatch" rather than false alarms. Added regime assignment (pre-drift / drift / post-drift, where an unmatched detection counts as pre-drift) and the synthetic-detection metrics (detection delay, false alarms per 10,000, missed detections). Later commits added tier support and changed the output format. | Table 1 & 2 |

The tuned config lowered full-test MAE from about 202.5 to 194.5 on SA1 and from about 758.7 to 748.8 on NSW1. The forecaster itself gained cyclical calendar features, momentum and rolling features, and regularisation parameters. | XGBoost tuning |
