# Table 5 - Fixed Split Conformal Evaluation

## 1. Overview

This folder contains my independent implementation of Fixed Split Conformal Prediction for Table 5 of our capstone project, "Detecting and Adapting to Concept Drift in Time Series Forecasting".

The main aim of this work is to check how well the prediction intervals cover the actual electricity demand values before, during, and after concept drift.

I used the AEMO NSW1 and SA1 datasets, XGBoost forecasts, and Page-Hinkley drift detection. The evaluation includes four adaptation arms (A, B, C, and D) and five random seeds (1 to 5).

The target prediction interval coverage is 90%.

## 2. Files and Folders

### scripts/

This folder contains the Python scripts I used for the evaluation.

- `conformal.py` - Calculates the conformal radius using calibration residuals and creates prediction intervals.
- `metrics.py` - Calculates coverage, mean interval width, normalised interval width, and worst 24-hour coverage.
- `prepare_forecasts.py` - Checks and prepares the forecast data and assigns the drift regimes.
- `run_table5.py` - Runs the evaluation for each region, seed, adaptation arm, and drift regime.
- `summarise_table5.py` - Calculates the mean and standard deviation across five seeds.

### data/

This folder contains the input CSV files used for the evaluation.

- `adaptation_forecasts/arm_A/` - Forecasts without retraining.
- `adaptation_forecasts/arm_B/` - Forecasts with retraining every 30 days.
- `adaptation_forecasts/arm_C/` - Forecasts with drift-triggered retraining using full history.
- `adaptation_forecasts/arm_D/` - Forecasts with drift-triggered retraining using the most recent 180 days.
- `calibration/` - Calibration forecasts and residuals used to calculate the conformal radius.

Each adaptation arm contains 10 CSV files, with five seeds for each region. The calibration folder also contains 10 CSV files.

The 40 prepared forecast files are generated by `prepare_forecasts.py`, so they are not uploaded separately.

### outputs/

This folder contains the final evaluation results.

- `table5_seed_results.csv` - Contains 120 results for all regions, seeds, adaptation arms, and drift regimes.
- `table5_final.csv` - Contains 24 summarised results with the mean and standard deviation across five seeds.

## 3. Methodology

### Fixed Split Conformal Prediction

I used Fixed Split Conformal Prediction to create 90% prediction intervals for the XGBoost forecasts.

First, I calculated the absolute residuals from the calibration forecasts. Then, I used these residuals to calculate the conformal radius.

The conformal radius was calculated separately for each region and seed.

I used the same conformal radius for all four adaptation arms within each region and seed.

The prediction intervals were calculated using:

- Lower bound = Forecast - Conformal radius
- Upper bound = Forecast + Conformal radius

### Drift Regimes

The evaluation was carried out separately for three regimes:

- Pre-drift - The period before a detected drift event.
- Drift - The period associated with detected drift events.
- Post-drift - The period after drift.

The Page-Hinkley drift results were used to assign the regimes.

### Evaluation Metrics

I calculated four evaluation metrics.

1. Coverage - The proportion of actual demand values that fall inside the prediction intervals.
2. Mean interval width - The average width of the prediction intervals in MW.
3. Normalised interval width - The mean interval width divided by the mean demand from the training dataset.
4. Worst 24-hour coverage - The lowest coverage found across complete 24-hour windows.

For worst 24-hour coverage, I used 48 consecutive half-hourly observations. Each window must stay within the same drift regime. Overlapping windows were also included.

The metrics were calculated for each region, adaptation arm, seed, and drift regime.

## 4. Running the Evaluation

The scripts should be run in the following order from the main repository folder.

```bash
python table5/scripts/prepare_forecasts.py
python table5/scripts/run_table5.py
python table5/scripts/summarise_table5.py
```

The first script prepares the forecast files. The second script calculates the evaluation metrics. The third script summarises the results across five seeds.

The main Python libraries used are pandas and NumPy.

## 5. Results and Observations

The independent evaluation produced results that were broadly similar to the team's Table 5.

Arm C generally achieved better average coverage during drift and post-drift compared with the other adaptation arms.

Arm D showed lower coverage, especially during the post-drift period.

I also observed that worst 24-hour coverage was much lower than average coverage in several cases. Some windows had zero coverage even when the overall coverage was relatively high.

This shows that average coverage alone does not fully explain how reliable the prediction intervals are during concept drift.

The mean interval widths were similar to the team's results, although there were some differences in coverage and worst 24-hour coverage.
